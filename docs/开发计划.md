## 1. 里程碑与前后端协调

```
M0 数据库就绪 ──> M1 后端骨架+登录 ──> M2 前端骨架+登录页 ──> M3~M6 业务模块成对推进 ──> M7 整体验收
```

| 里程碑 | 后端交付 | 前端交付 | 成对验收点 |
| --- | --- | --- | --- |
| M0 数据库 | schema.sql + data.sql 执行验证 | — | 7 表 + admin + 演示数据可用 |
| M1/M2 骨架 | 登录接口、/api/users/me、安全框架 | 工程初始化、登录页、布局与路由守卫 | 浏览器 admin 登录拿到真实 token |
| M3 用户模块 | 注册、登录完善、个人信息 | 注册页、个人信息页 | 注册→登录→改信息闭环 |
| M4 主题套餐 | 12 个接口 | 管理端 CRUD 页、用户端浏览页 | 下架即不可见 |
| M5 订单 | 下单/列表/详情/状态机/管理端处理 | 下单页、我的订单、管理端订单页 | 8 状态流转 + 权限用例通过 |
| M6 照片 | 上传/水印/预览/下载 | 上传页、照片墙、下载 | 权限（交付前不可下原图）通过 |
| M7 反馈交付 | 反馈、交付、时间线 | 反馈页、交付确认、时间线 | 完整业务闭环跑通 |

协调规则：
1. 后端接口以 `docs/API接口约定.md` 为准，前端**不等后端完成才开工**——接口未就绪时按契约做本地 Mock（明确标注 Mock），接口就绪后切换真实地址并联调。
2. 每个里程碑由前后端各自计划的验收项组成，成对验收通过才算该里程碑完成。
3. 前后端计划各自独立推进、独立提交，互不阻塞；需要对方配合时在本表登记协调点。

## 2. 已确认的技术选型（团队拍板，不再讨论）

| 项 | 决议 |
| --- | --- |
| 后端 | Spring Boot 3.x + JDK 17 + Maven 3.9 |
| 数据访问 | MyBatis-Plus 3.5.x（Spring Boot 3 适配版） |
| 认证鉴权 | Spring Security + JWT（有效期 24 小时），`/api/admin/**` 仅 ADMIN |
| 密码 | BCrypt，接口永不返回 password |
| 前端 | Vite + Vue 3 + TypeScript + Element Plus + Vue Router + Pinia + Axios |
| 数据库 | MySQL 8.x，库名 `photography`，utf8mb4 / InnoDB，7 张表按《数据库设计》2.3 节 |
| 照片存储 | 服务器本地 `uploads/{订单ID}/`，数据库只存相对路径；水印图后缀 `_wm` |
| 管理员预置 | 初始化脚本固定账号 `admin` / 初始密码 `admin123456`（BCrypt 存储，README 注明首登后修改） |
| 端口 | 后端 8080，前端 dev 5173，Vite 代理 `/api → localhost:8080` |
| 字段映射 | JSON camelCase，数据库 snake_case，映射层转换 |
| 备注长度 | 接口层校验 ≤200 字；DB 字段保持 VARCHAR(500)（API 约定 X-02） |
| 主题/套餐删除 | 只做软下架（status=0），不提供物理删除接口（API 约定 T-01） |

### 2.2 敏感配置约定

- 数据库密码、JWT 密钥只放 `backend/src/main/resources/application-local.yml`（已 gitignore）。
- 仓库提供 `application-example.yml` 占位模板（假值），真实凭证不进 Git。
- 首次搭建时在 `application-local.yml` 写入一个随机 JWT 密钥。
- 数据库初始化凭据仅用于本地执行，不写入任何项目文件。

## 3. 公共工程约定

1. 每批/每阶段一个功能分支（或沿用 `feat/scaffold` 按阶段提交），合并回 main 前跑 `mvn package` 与 `npm run build`。
2. 提交说明如实描述修改内容；不提交 `uploads/`、本地配置、构建产物、`.idea`。
3. 每阶段结束按 AGENTS.md 第 14 节出完成报告（功能/文件/方案/验证结果/遗留风险/影响面）。
4. 业务规则以三份源文档 + `API接口约定.md` 为准；发现新冲突先登记待确认，不擅自决定。
5. 敏感信息（密码、密钥、token）不入代码、不入日志。
6. Mock 数据必须显式标注，不得冒充已联调功能。
